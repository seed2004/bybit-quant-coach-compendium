# Bybit Options-Income Quant-Coach — Design & Knowledge Compendium

This repository documents the **design, engineering approach, and usage** of a private
options-income trading dashboard for crypto options. It began on Bybit and now supports
two venues, including a coin-margined (inverse-settled) book. It is a
**knowledge/ideas repository only** — it contains the concepts, models, formulas,
architecture, and hard-won lessons behind the system, but **no source code**.

The goal is to make the *thinking* reusable — for the author's future reference and for
anyone building a similar decision-support tool — without publishing the implementation.

---

## What the system is (one paragraph)

A single-operator **quant coach** for manual options-income trading. It ingests public
market data (option chains, perpetual index/funding, daily candles) from the account's own
venue, plus the trader's *read-only* positions, and turns them into regime analysis,
transparent strategy scoring, **executable** (not mid) pricing, position-management prompts
including roll economics and theta efficiency, risk/margin accounting, a monthly-income
layer that asks whether the book can actually be lived off, and — critically — a learning
loop that calibrates its advice to the trader's own realized results. **It never places
orders.** Every trade is executed by the human on the exchange; the software only analyzes,
scores, explains, and remembers.

## What is intentionally NOT here

- **No source code** — no Python, no JavaScript, no configuration files.
- **No secrets** — no API keys, account identifiers, credentials, or personal balances.
- **No proprietary exchange data** — only publicly documented mechanics (fee formulas,
  margin formulas) that any user of those exchanges can read in their own help pages.

## Disclaimer

Nothing here is financial advice. The system it describes is a personal decision-support
tool; it produces data synthesis and rule-based scoring, not recommendations to buy or
sell. Options trading, and short-premium trading in particular, carries the risk of large
and in some structures unbounded losses.
